# Logistic Regression and Classification Types

Logistic Regression is not only called **binary classification** — but it is **commonly used for binary classification tasks**.

## ✅ Binary Logistic Regression
This is the most common form.

Used when the target variable has **two classes**, like:
- Yes / No  
- Spam / Not Spam  
- Disease / No Disease  

**Output** is a probability between **0 and 1**, typically thresholded at **0.5**.

---

## ✅ Multinomial Logistic Regression
Also known as **Softmax Regression**.

Used when the target has **more than two classes**, like:
- Cat / Dog / Bird

This is an **extension** of binary logistic regression.

---

## ✅ Ordinal Logistic Regression
Used when the classes are **ordered**, like:
- Low / Medium / High

---

## 📌 Conclusion
When someone says **“logistic regression”** casually, they usually mean **binary logistic regression**.

But logistic regression can be extended for **multiclass** or **ordinal** classification.
