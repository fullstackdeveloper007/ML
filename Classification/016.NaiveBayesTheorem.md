# 🤖 Naive Bayes Theorem Explained

## 🔍 What is Naive Bayes?

**Naive Bayes** is a simple and powerful classification algorithm based on **Bayes’ Theorem** with a **naive assumption**:  
> All features are conditionally independent given the class.

---

## 📘 Bayes’ Theorem

Bayes' Theorem formula:

P(A | B) = (P(B | A) * P(A)) / P(B)

In classification terms:

- P(y | x): Probability of class y given features x  
- P(x | y): Likelihood of features x under class y  
- P(y): Prior probability of class y  
- P(x): Evidence (total probability of features)

---

## 🧠 Naive Assumption

Naive Bayes assumes that each feature xi is independent given the class:

P(x1, x2, ..., xn | y) = P(x1 | y) * P(x2 | y) * ... * P(xn | y)

So the model predicts the class y with the highest:

P(y) * P(x1 | y) * P(x2 | y) * ... * P(xn | y)

---

## 🧪 Example

Assume:
- Two classes: `spam`, `ham`
- Features: presence of words like `free`, `money`, `offer`

The model calculates:

P(spam | free, money) ∝ P(spam) * P(free | spam) * P(money | spam)

Repeat for each class and choose the one with the higher result.

## 📦 Types of Naive Bayes

| Type            | Suitable For               | Assumes                          |
|-----------------|----------------------------|----------------------------------|
| Gaussian NB     | Continuous features         | Normal distribution              |
| Multinomial NB  | Count data (e.g. word freq) | Feature counts                   |
| Bernoulli NB    | Binary features             | Presence/absence of a feature    |

---

## ✅ Pros

- Simple and fast
- Works well with high-dimensional data (e.g., text)
- Performs well with small datasets

## ❌ Cons

- Assumes feature independence (rare in real life)
- Less accurate when features are correlated

---

## 📌 Use Cases

- Email spam detection
- Sentiment analysis
- Document categorization
- Medical diagnosis

---

## 💡 Summary

Naive Bayes is:
- A **probabilistic** model
- Based on **Bayes' Theorem**
- Assumes **independence** between features
- Often used for **text classification**
