# 🎴 Understanding Probability with a Deck of Cards

## 🃏 What's in a Standard Deck?

* **Total cards**: 52
* **4 suits**: Hearts, Diamonds, Clubs, Spades
* Each suit has **13 cards**: A, 2–10, J, Q, K
* **26 red cards**: Hearts + Diamonds
* **26 black cards**: Clubs + Spades

---

## 🧮 Basic Probability Formula:

```math
Probability = \frac{Favorable\ Outcomes}{Total\ Possible\ Outcomes}
```

---

## ✅ Examples

### 1. Probability of Drawing a King

* Favorable outcomes: 4 Kings
* Total outcomes: 52

```math
P(King) = \frac{4}{52} = \frac{1}{13}
```

### 2. Probability of Drawing a Red Card

* Red cards: 26

```math
P(Red) = \frac{26}{52} = \frac{1}{2}
```

### 3. Probability of Drawing a Heart

* Hearts in deck: 13

```math
P(Heart) = \frac{13}{52} = \frac{1}{4}
```

### 4. Probability of Drawing a Face Card (J, Q, K)

* 3 face cards per suit × 4 suits = 12

```math
P(Face\ Card) = \frac{12}{52} = \frac{3}{13}
```

### 5. Probability of NOT Drawing an Ace

* Aces: 4 → Non-Aces: 52 - 4 = 48

```math
P(Not\ Ace) = \frac{48}{52} = \frac{12}{13}
```

---

## 🔁 Conditional Probability

### If one card is drawn and it's a Spade, what's the probability it's a King?

* Cards left to consider: 13 Spades
* Only 1 King of Spades

```math
P(King | Spade) = \frac{1}{13}
```

---

## 🔄 Independent Events

### Drawing Two Cards **with replacement**:

* First draw: P(Ace) = 4/52
* Second draw: P(Ace) = 4/52 again

```math
P(2\ Aces) = \frac{4}{52} \times \frac{4}{52}
```

### Drawing Two Cards **without replacement**:

* First draw: P(Ace) = 4/52
* Second draw: P(Ace) = 3/51

```math
P(2\ Aces) = \frac{4}{52} \times \frac{3}{51}
```

## 🧠 Summary Table

| Type                    | Formula                  |                        |
| ----------------------- | ------------------------ | ---------------------- |
| Basic Probability       | P(A) = Favorable / Total |                        |
| Not A                   | P(not A) = 1 - P(A)      |                        |
| And (independent)       | P(A and B) = P(A) × P(B) |                        |
| Conditional             | P(A                      | B) = P(A and B) / P(B) |
| Or (mutually exclusive) | P(A or B) = P(A) + P(B)  |                        |
