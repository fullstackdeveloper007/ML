# 🧪 Data Preprocessing Techniques for Classification and Regularization

## 1. Handling Missing Values
- Drop rows/columns
- Impute (mean/median/mode)
- KNN imputation

## 2. Encoding Categorical Variables
- Label Encoding
- One-Hot Encoding
- Ordinal Encoding

## 3. Feature Scaling
- **StandardScaler:** Zero mean, unit variance (for SVM, Logistic Regression)
- **MinMaxScaler:** Scale to [0,1]
- **RobustScaler:** Resistant to outliers

## 4. Feature Engineering
- Polynomial features
- Log transforms
- Binning

## 5. Dimensionality Reduction
- **PCA:** Projects data into fewer components
- **LDA:** For classification

## 6. Outlier Detection
- Z-score, IQR
- Isolation Forest

## 7. Data Balancing
- Undersampling
- Oversampling (SMOTE)
- Class weighting

---

## 🔧 Regularization vs Preprocessing

| Regularization | Affected by Preprocessing? | Notes |
|----------------|----------------------------|-------|
| **L1 (Lasso)** | Yes                        | Helps in feature selection |
| **L2 (Ridge)** | Yes                        | Improves generalization |
| **ElasticNet** | Yes                        | Mix of L1 and L2 |

---

## ✅ Best Practices
- Scale data for regularized models
- Avoid target leakage
- Use pipelines for clean workflows
