# Handling Class Imbalance in Machine Learning

Class imbalance occurs when one class significantly outnumbers the other(s). This can lead to biased models that fail to detect the minority class correctly. There are several resampling techniques to handle this issue.

---

## 🔁 1. Oversampling Techniques

Oversampling increases the number of samples in the **minority class**.

### 🔹 1.1 Random Oversampling

**Description**: Randomly duplicates samples from the minority class.

```python
from imblearn.over_sampling import RandomOverSampler
from collections import Counter
from sklearn.datasets import make_classification

X, y = make_classification(n_classes=2, weights=[0.9, 0.1],
                           n_samples=1000, n_features=20, random_state=42)
print("Before:", Counter(y))

ros = RandomOverSampler(random_state=42)
X_res, y_res = ros.fit_resample(X, y)
print("After:", Counter(y_res))

## 1.2 SMOTE (Synthetic Minority Over-sampling Technique)
Description: Creates synthetic examples of the minority class by interpolating between neighbors.
```
from imblearn.over_sampling import SMOTE

smote = SMOTE(random_state=42)
X_res, y_res = smote.fit_resample(X, y)
print("After SMOTE:", Counter(y_res))

```
## 1.3 ADASYN (Adaptive Synthetic Sampling)
Description: Similar to SMOTE but focuses more on harder-to-learn samples.

```python
from imblearn.over_sampling import ADASYN

adasyn = ADASYN(random_state=42)
X_res, y_res = adasyn.fit_resample(X, y)
print("After ADASYN:", Counter(y_res))

```

# 2. Undersampling Techniques
Undersampling reduces the number of samples in the majority class.

## 2.1 Random Undersampling
Description: Randomly removes samples from the majority class.

```python
from imblearn.under_sampling import RandomUnderSampler

rus = RandomUnderSampler(random_state=42)
X_res, y_res = rus.fit_resample(X, y)
print("After Random Undersampling:", Counter(y_res))

```

## 2.2 Tomek Links
Description: Removes borderline majority samples that are closest to minority samples.

```python
from imblearn.under_sampling import TomekLinks

tl = TomekLinks()
X_res, y_res = tl.fit_resample(X, y)
print("After Tomek Links:", Counter(y_res))

```
## 2.3 Edited Nearest Neighbors (ENN)
Description: Removes samples (usually from majority) that differ from their neighbors.

```python
from imblearn.under_sampling import EditedNearestNeighbours

enn = EditedNearestNeighbours()
X_res, y_res = enn.fit_resample(X, y)
print("After ENN:", Counter(y_res))
```

# 3. Hybrid Techniques
## 3.1 SMOTE + Tomek Links
Description: Combines SMOTE (oversampling) and Tomek Links (cleaning).

```
from imblearn.combine import SMOTETomek

smt = SMOTETomek(random_state=42)
X_res, y_res = smt.fit_resample(X, y)
print("After SMOTE-Tomek:", Counter(y_res))

```

 3.2 SMOTE + ENN
Description: Combines SMOTE with ENN for stronger cleaning.
```
from imblearn.combine import SMOTEENN

sme = SMOTEENN(random_state=42)
X_res, y_res = sme.fit_resample(X, y)
print("After SMOTE-ENN:", Counter(y_res))

```

### Notes
- Always perform resampling only on the training set, not on the test set.
- Evaluate model using precision, recall, F1-score, and ROC-AUC, not just accuracy.
- These techniques are available in the imbalanced-learn (imblearn) library.
