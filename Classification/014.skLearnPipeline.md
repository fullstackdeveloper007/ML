# 🔧 Scikit-Learn Pipeline

## 📌 What is a Pipeline?

A `Pipeline` in `scikit-learn` helps **streamline the preprocessing and modeling steps** into a single object. It ensures that data transformation and model training/testing are performed in a **consistent and repeatable way**.

---

## ✅ Why Use Pipelines?

- Prevent **data leakage** between training and testing.
- Combine **multiple steps** (e.g., scaling, encoding, modeling) into one flow.
- Make **cross-validation and grid search** easier and safer.
- Improve **code readability and reproducibility**.

---

## ⚙️ Structure of a Pipeline

A pipeline is a sequence of steps where each step except the last must be a **transformer** (i.e., implement `fit` and `transform`), and the last step is usually a **predictor** (implements `fit` and `predict`).

## Example: Classification Pipeline
```python
from sklearn.pipeline import Pipeline

pipeline = Pipeline([
    ('scaler', StandardScaler()),
    ('classifier', LogisticRegression())
])

from sklearn.datasets import load_iris
from sklearn.model_selection import train_test_split
from sklearn.preprocessing import StandardScaler
from sklearn.linear_model import LogisticRegression
from sklearn.pipeline import Pipeline

# Load data
X, y = load_iris(return_X_y=True)
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3, random_state=42)

# Build pipeline
clf_pipeline = Pipeline([
    ('scaler', StandardScaler()),
    ('classifier', LogisticRegression())
])

# Fit pipeline
clf_pipeline.fit(X_train, y_train)

# Predict
y_pred = clf_pipeline.predict(X_test)
```
