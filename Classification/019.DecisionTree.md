# Decision Trees

## 1. What is a Decision Tree?
A **Decision Tree** is a supervised machine learning model that splits data into subsets based on **feature values**, forming a tree-like structure.  
At each node, the algorithm selects the **best feature and threshold** to split the data so that the resulting child nodes are as "pure" as possible.

📌 **Use case:** Classification (e.g., spam detection, disease diagnosis) and regression tasks.

---

## 2. How a Decision Tree Works (Classification)
1. Start with the full dataset at the root node.
2. At each node:
   - Evaluate all features and possible split points.
   - Choose the split that produces the "purest" child nodes.
3. Continue splitting recursively until:
   - Maximum depth reached
   - Minimum number of samples per node reached
   - All nodes are pure (contain only one class)
4. Predict the class of a sample based on the **majority class** in its leaf node.

---

## 3. Measuring Purity

Purity means how homogeneous the class labels are in a node.

### **A. Gini Impurity**
- Measures the probability of **incorrectly classifying** a randomly chosen sample from the node.
- Formula: Gini(t) = 1 - Σ (p_i)^2
  
Where:
- `p_i` = proportion of samples belonging to class `i` in node `t`
- `Σ` = sum over all classes

**Example:**
Node has 4 samples: 3 from Class A, 1 from Class B  


- **Lower Gini → purer node**.
---

### **B. Entropy (Information Gain)**
- Measures the level of **disorder** in a node.
- Formula:
Entropy(t) = - Σ [ p_i * log2(p_i) ]  

Where:
- `p_i` = proportion of samples belonging to class `i` in node `t`

 
**Example:**
Where:
- `p_i` = proportion of samples belonging to class `i` in node `t`

**Example:**

- **Lower entropy → purer node**.

---

## 4. Choosing Between Gini and Entropy
- **Gini Impurity**: Faster to compute, works well in practice.
- **Entropy**: Based on information theory, can be more interpretable in terms of information gain.
- **Scikit-learn default**: Gini Impurity.

---

## 5. Information Gain (Entropy-based)
When splitting a node:
Information Gain = Entropy(parent) - Weighted Avg Entropy(children)

- The split with the **highest information gain** is chosen.
---

## 6. Advantages of Decision Trees
✅ Easy to understand and visualize  
✅ Can handle both numerical and categorical data  
✅ No need for feature scaling  
✅ Works for multi-class classification  

---

## 7. Disadvantages of Decision Trees
❌ Prone to overfitting if not pruned  
❌ Can be unstable (small data changes → different tree)  
❌ Greedy algorithm may not find the global best tree  

---

## 8. Example in Python (Classification)
```python
from sklearn.datasets import load_iris
from sklearn.tree import DecisionTreeClassifier, export_text

X, y = load_iris(return_X_y=True)
clf = DecisionTreeClassifier(criterion='gini', max_depth=3, random_state=42)
clf.fit(X, y)

# Show tree structure
tree_rules = export_text(clf, feature_names=load_iris().feature_names)
print(tree_rules)
```
