# Overfitting vs Underfitting in Machine Learning

In machine learning, the goal is to create models that generalize well to new, unseen data. Two common problems that hinder this goal are **Overfitting** and **Underfitting**.

- **Overfitting** occurs when the model learns not just the underlying pattern but also the noise in the training data. It performs very well on training data but poorly on test or unseen data.
- **Underfitting** happens when the model is too simple to capture the underlying trends in the data, resulting in poor performance on both training and test sets.

Understanding the reasons behind both helps in building more accurate and reliable models.

# Overfitting vs Underfitting in Machine Learning

## Reasons of **Overfitting**

Overfitting occurs when a model performs well on the training data but poorly on unseen test data. Below are common reasons with examples:

### 1. Poor Model
- **Example**: Using a deep neural network with many layers for a small tabular dataset like predicting house prices with only 100 rows. The model memorizes training data instead of learning general patterns.

### 2. Hyperparameter Selection
- **Example**: Setting too many estimators in a `RandomForestClassifier(n_estimators=1000)` can lead to overfitting, especially if `max_depth` is not limited.

### 3. Insufficient Training Data
- **Example**: Training a model with only 20 images per class in an image classification task (like cats vs dogs) — the model learns specific features of the limited examples.

### 4. Poor Feature Selection
- **Example**: Including irrelevant features like `user_id`, `timestamp`, etc., in a model predicting loan approval may confuse the model and lead to overfitting.

### 5. Inadequate Validation (Train/Test Split or Cross-Validation)
- **Example**: Training a model on the entire dataset without using techniques like **K-Fold Cross Validation** leads to no performance check on unseen data.

### 6. Lack of Regularization
- **Example**: Not using L2 regularization (`alpha=0` in Ridge Regression) allows the model weights to grow large and fit noise in the training data.

---

## Reasons of **Underfitting**

Underfitting occurs when a model is too simple to capture the underlying pattern of the data. Below are common causes:

### 1. Model is Too Simple
- **Example**: Using simple linear regression `price = B0 + B1 * mileage` instead of polynomial regression `price = B0 + B1 * mileage + B2 * mileage²` to predict car price. The linear model fails to capture non-linear patterns.

### 2. Insufficient Training Data
- **Example**: Training an SVM classifier on only 10% of the full dataset results in a model that doesn't learn enough about the problem space.

### 3. Insufficient Feature / Poor Feature Engineering
- **Example**: Predicting customer churn with only age and income, missing key features like usage history, service calls, and plan type.

### 4. Insufficient Training Time
- **Example**: Training a neural network for only 100 epochs when convergence needs 200. The model is stopped before it has fully learned the data.

### 5. Excessive Regularization
- **Example**: Using a very high L2 regularization term (`alpha = 100`) in Ridge Regression heavily penalizes coefficients, making the model too rigid and underfit the data.

---

## Tips to Address Overfitting and Underfitting

- Use cross-validation to monitor model performance.
- Tune hyperparameters using grid search or random search.
- Regularize appropriately (L1/L2, dropout for neural nets).
- Engineer better features and gather more data where possible.
- Choose the right model complexity for your dataset.
