# 🤖 Supervised Machine Learning Models

Supervised ML uses **labeled data** (with known outcomes), such as:

- Name, type, or number
- Pizza/Donuts order
- Bill amount
- Future forecasting of tips or bills

---

## 🎓 What is Supervised Learning?

Supervised learning **learns from being given the right answer** — the model is trained on labeled data where both input and output are known.

Supervised machine learning is primarily categorized into two types:

---

## 1. 🧩 Classification

### 🔍 Description:
Classification is a type of supervised learning where the goal is to **predict a category or class label** for a given input based on prior labeled examples.

### 📦 Examples:
- Spam detection → **Spam / Not Spam**
- Disease diagnosis → **Positive / Negative**
- Handwritten digit recognition → **0–9**

### ✅ Use Case:
Predicting discrete/categorical values.

---

## 2. 📈 Regression

### 🔍 Description:
Regression is used when the output is a **real (continuous) number**.  
It finds the relationship between **input variables** (independent variables) and an **output variable** (dependent variable).

### 📦 Examples:
- Predicting house prices
- Estimating stock market trends
- Forecasting sales or demand

### ✅ Use Case:
Predicting numerical values with **infinitely many possible outputs**.

---

## 🧠 Summary: Classification vs Regression

| Type          | Goal                        | Output Type         | Examples                                      |
|---------------|-----------------------------|----------------------|-----------------------------------------------|
| Classification| Predict category/class      | Discrete labels      | Spam detection, disease diagnosis, digit recognition |
| Regression    | Predict a number            | Continuous values    | House prices, stock trends, demand forecasting     |

---

## 📌 Example of Supervised ML

Given past data on house size, location, and number of rooms, a supervised ML model can:

- **Classify** if a house is in a “High Price” or “Low Price” category (Classification)
- **Predict** the exact price of the house in dollars (Regression)
