# Voting

Voting is one of the simplest ensemble techniques.
You train multiple different models and then combine their predictions to make a final decision.

Think of it like:
“A group of friends voting on where to eat — majority wins.”

## 2. Types of Voting
### A. Hard Voting
Each model predicts a class label.

The class that gets the most votes becomes the final prediction.
Model1 → Class A  
Model2 → Class A  
Model3 → Class B  
Final (Majority) → Class A

### B. Soft Voting

Each model predicts class probabilities (e.g., [0.2, 0.8] meaning 80% chance of class 1).
The probabilities from all models are averaged.
The class with the highest average probability is the final prediction.
Model1: [0.3, 0.7]  
Model2: [0.4, 0.6]  
Model3: [0.2, 0.8]  

Average: [0.3, 0.7] → Class 1

C. Weighted Voting
You give more importance (weight) to certain models.
Useful if some models are known to perform better.
Example (soft voting with weights):

```python
from sklearn.ensemble import VotingClassifier
from sklearn.linear_model import LogisticRegression
from sklearn.tree import DecisionTreeClassifier
from sklearn.svm import SVC
from sklearn.datasets import load_iris
from sklearn.model_selection import train_test_split

# Load data
X, y = load_iris(return_X_y=True)
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3, random_state=42)

# Base models
clf1 = LogisticRegression(max_iter=200)
clf2 = DecisionTreeClassifier()
clf3 = SVC(probability=True)  # Needed for soft voting

# Soft voting ensemble
ensemble = VotingClassifier(
    estimators=[('lr', clf1), ('dt', clf2), ('svc', clf3)],
    voting='soft',  # 'hard' for hard voting
    weights=[2, 1, 2]  # Optional weights
)

ensemble.fit(X_train, y_train)
print("Voting Ensemble Accuracy:", ensemble.score(X_test, y_test))

```
