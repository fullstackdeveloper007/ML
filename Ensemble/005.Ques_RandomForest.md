# Key Points to Remember for Interviews

- Random Forest = Bagging + Random Feature Selection
- Each tree is trained on a different bootstrap sample
- At each split, only a subset of features is considered
- Reduces variance, keeps bias low
- Works well for both classification & regression
- OOB score is an internal validation metric
- Can rank features by importance
- Not ideal for sparse high-dimensional data
- Parallelizable → training can be faster on multi-core CPUs

## Common Interview Questions & Answers
### Q1: What is the main difference between Bagging and Random Forest?
A: Bagging uses all features at each split, while Random Forest uses a random subset of features at each split, increasing diversity among trees.

### Q2: Why does Random Forest reduce overfitting?
A: By training multiple trees on different data samples and using random subsets of features, it reduces the correlation between trees, lowering variance and preventing overfitting.

### Q3: How does Random Forest handle missing data?
A: It can still make predictions if some features are missing by using surrogate splits or ignoring missing features in splits.

### Q4: How is feature importance calculated in Random Forest?
- A:Mean Decrease in Impurity (MDI) — Sum of impurity reduction (Gini/Entropy) for each feature across all trees.
- Permutation Importance — Randomly shuffle a feature and see how much accuracy drops.

### Q5: What is the Out-of-Bag (OOB) score?
A: OOB score is an estimate of the model’s performance using the ~37% of samples not included in the bootstrap sample for each tree, avoiding the need for a separate validation set.

### Q6: What happens if max_features is too high?
A: Trees will be more correlated, reducing the benefit of ensembling and possibly leading to overfitting.

### Q7: Can Random Forest be used for regression?
A: Yes — RandomForestRegressor averages predictions from all trees instead of using majority vote.

### Q8: How does Random Forest handle categorical features in Scikit-learn?
A: Scikit-learn requires categorical features to be encoded numerically (e.g., one-hot encoding).

### Q9: What is the effect of increasing n_estimators?
A: Accuracy may improve up to a point, but training time and memory usage will also increase.

### Q10: Is Random Forest a parametric or non-parametric method?
A: Non-parametric — it makes no assumptions about the data distribution.
