
## **1. What’s Happening in Model 1**

In **Gradient Boosting**, Model 1 is simply the **first weak learner** (often a decision tree or a simple regression model) trained to predict the **target variable (y)** directly — *not residuals yet*.

So, in **Iteration 1**:

* **Input (X)** = Features like rooms, area, location score, etc.
* **Output (y)** = Actual house price.
* We train the weak learner using **ordinary regression** (like decision tree regression, linear regression, etc.) to fit y.

---

## **2. Using a Simple Regression Model for h₁(x)**

If we use a **linear regression model** as the weak learner:

The formula is:

$$
h₁(x) = β₀ + β₁X₁ + β₂X₂ + \dots + βₙXₙ
$$

Where:

* **β₀** = Intercept
* **β₁...βₙ** = Coefficients learned from training
* **X₁...Xₙ** = Feature values for a given house

---

### **Example Data (Iteration 1)**

| House | Rooms (X₁) | Area (sqft) (X₂) | Location Score (X₃) | Actual Price (y) |
| ----- | ---------- | ---------------- | ------------------- | ---------------- |
| 1     | 3          | 2000             | 8                   | 500,000          |
| 2     | 2          | 1200             | 6                   | 300,000          |
| 3     | 4          | 2500             | 9                   | 600,000          |
| 4     | 3          | 1800             | 5                   | 350,000          |

---

### **Step 1 — Fit Linear Regression**

We fit:

$$
y = β₀ + β₁(\text{Rooms}) + β₂(\text{Area}) + β₃(\text{Location Score})
$$

Let’s say after training, we get:

* β₀ = 50,000
* β₁ = 20,000
* β₂ = 100
* β₃ = 15,000

---

### **Step 2 — Predict h₁(x)**

For House 1:

$$
h₁(x₁) = 50,000 + (20,000 \times 3) + (100 \times 2000) + (15,000 \times 8)
$$

$$
= 50,000 + 60,000 + 200,000 + 120,000 = 430,000
$$

We repeat for all houses:

| House | Predicted Price h₁(x) |
| ----- | --------------------- |
| 1     | 430,000               |
| 2     | 320,000               |
| 3     | 590,000               |
| 4     | 360,000               |

---

### **Step 3 — Compute Residuals**

$$
\text{Residual} = y - h₁(x)
$$

| House | y (Actual) | h₁(x) (Predicted) | Residual |
| ----- | ---------- | ----------------- | -------- |
| 1     | 500,000    | 430,000           | 70,000   |
| 2     | 300,000    | 320,000           | -20,000  |
| 3     | 600,000    | 590,000           | 10,000   |
| 4     | 350,000    | 360,000           | -10,000  |

These **residuals** become the new **target (y')** for the second weak learner in Iteration 2.

---

✅ In short:

* **Model 1** is trained just like a **normal regression model** (could be linear regression or decision tree regression).
* The predictions **h₁(x)** are the outputs from that model.
* Then, residuals are calculated for **boosting**.
