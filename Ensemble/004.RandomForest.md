# 🌳 Random Forest — Complete Guide

## 1. What is Random Forest?
Random Forest is an **ensemble learning algorithm** that builds multiple **decision trees** and combines their predictions for better accuracy and generalization.  
It is a type of **bagging** method, but with an extra twist — **random feature selection**.

📌 **Key idea:**  
- Bagging = Train multiple trees on bootstrap samples  
- Random Forest = Bagging + Random subset of features at each split

---

## 2. Why Random Forest?
- Reduces **overfitting** compared to a single decision tree
- Handles **high-dimensional** data
- Works for both **classification** and **regression**
- Robust against noisy data and missing values

---

## 3. How Random Forest Works
1. **Bootstrap sampling**:  
   Randomly sample data with replacement to create multiple datasets for each tree.
2. **Random feature selection**:  
   At each split in a tree, only consider a **random subset of features** instead of all features.
3. **Train multiple decision trees** in parallel.
4. **Aggregate predictions**:  
   - Classification → Majority vote (hard voting)  
   - Regression → Average of predictions

---

## 4. Key Parameters (Scikit-Learn)
| Parameter | Description | Common Choices |
|-----------|-------------|----------------|
| `n_estimators` | Number of trees in the forest | 100–500 (or more) |
| `max_features` | Number of features to consider at each split | `sqrt` (classification), `log2`, or integer |
| `max_depth` | Max depth of trees | None (grow fully) or set limit to prevent overfitting |
| `min_samples_split` | Min samples to split a node | Default: 2 |
| `min_samples_leaf` | Min samples per leaf node | Default: 1 |
| `bootstrap` | Use bootstrap samples? | True (default) |

---

## 5. Advantages
✅ Handles both classification and regression  
✅ Reduces overfitting compared to single trees  
✅ Works well with large datasets and many features  
✅ Robust to outliers and noise  
✅ Can estimate **feature importance**

---

## 6. Disadvantages
❌ Less interpretable than a single decision tree  
❌ Slower prediction compared to one tree (more trees → slower)  
❌ Uses more memory  
❌ Not great for very sparse, high-dimensional data (e.g., NLP without embeddings)

---

## 7. Feature Importance
Random Forest can tell you which features are most important by:
- **Mean Decrease in Impurity (MDI)** → Based on Gini/Entropy reduction
- **Mean Decrease in Accuracy (MDA)** → Based on permutation testing

---

## 8. Out-of-Bag (OOB) Error
- Since each tree is trained on a bootstrap sample (~63% of data), the remaining ~37% (**OOB samples**) can be used to estimate prediction error without a separate validation set.
- Set `oob_score=True` in Scikit-Learn.

---

## 9. Example in Python
```python
from sklearn.ensemble import RandomForestClassifier
from sklearn.datasets import load_iris
from sklearn.model_selection import train_test_split

# Data
X, y = load_iris(return_X_y=True)
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3, random_state=42)

# Model
rf = RandomForestClassifier(
    n_estimators=100,
    max_features='sqrt',
    oob_score=True,
    random_state=42
)

rf.fit(X_train, y_train)
print("Test Accuracy:", rf.score(X_test, y_test))
print("OOB Score:", rf.oob_score_)
print("Feature Importances:", rf.feature_importances_)
